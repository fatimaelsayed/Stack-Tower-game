Stack Tower:
stack tower is a browser game that was built using plan HTML, CSS and JavaSscript. Blocks slide across the screen, you have to stack them as high as you can, and if you miss you lose and start over.

How to play:
.a block slides from left to right across the tower
.click to drop it
.any part that overhangs the block below is cut off, which will cause the tower to get narrower
.if the block missed the tower completely, the game is over
.the score respesents the number of block you have stacked

*with every successful landing, tthe speed increases which will cause the game to get harder as you go
